# mikroBUS™ Add-on Boards Collection

This repository contains a collection of add-on boards designed according to the mikroBUS™ standard. These boards can be used with any microcontroller platform that supports the mikroBUS™ socket, providing an easy way to expand the functionality of your projects.

* [**BluePill Base Board with 3 MikroBUS Sockets**](/BluePill_base/README.md)
* [**Arduino UNO Click Shield**](/Arduino_UNO_click_shield/README.md) - ![](https://img.shields.io/static/v1?label=&message=WIP&color=red) SPI to UART firmware

---

* [**CAN Click**](/CAN_Click/README.md)
* [**Ethernet W5500 mini Click**](/ETH_W5500_mini_Click/README.md)
* [**HLW8032 Click - energy metering module**](/HLW8032_Click/README.md)
* [**I²C to 1-Wire Click**](/I2C_1-Wire_Click/README.md)
* [**I²C EEPROM/FRAM Click**](/I2C_EEPROM_Click/README.md)
* [**LoRa Click**](/LoRa_Click/README.md)
* [**OpenTherm Click**](/OpenTherm_Click/README.md)
* [**RS485 Click**](/RS485_Click/README.md)
* [**UI Click with SCT-013 interface**](/SCT-013_UI_Click/README.md)
